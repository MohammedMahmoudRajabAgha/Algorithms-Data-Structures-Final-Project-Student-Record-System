# Algorithms & Data Structures Final Project – Student Record System

A university final project developed for the **Algorithms and Data Structures** course using **C++**.

The project is a console-based **Student Record System** designed to apply fundamental data structures and algorithms through practical operations such as managing students, grades, searching, sorting, queue processing, and history tracking.

## 📌 Project Overview

The system allows users to manage student records and perform different operations on student information and grades.

The project focuses on implementing fundamental data structures manually using pointers and dynamic memory, providing practical experience with how these structures work internally.

## ✨ Features

* Add and manage student records
* Search for students by Student ID
* Add, edit, and delete student grades
* Calculate student GPA
* Track completed credit hours
* Display student information and grades
* Sort students by:

  * GPA
  * Completed Hours
* Process students using a Queue
* Maintain search/operation history using a Stack
* Prevent duplicate student IDs
* Input validation
* Dynamic memory management

## 🧩 Data Structures

The project implements several fundamental data structures:

### Linked List

Used to store and manage:

* Student records
* Student grades

Students and grades are dynamically connected using pointers.

### Queue

A Queue is used to manage students waiting to be processed.

Operations include:

* Enqueue
* Dequeue
* Processing students in FIFO order

### Stack

A Stack is used to maintain operation/search history.

Operations include:

* Push
* Display history

## 🔎 Algorithms

The project applies several fundamental algorithms and concepts:

* Linear searching
* Bubble Sort
* Sorting by GPA
* Sorting by completed hours
* Duplicate detection
* GPA calculation
* Grade processing

## 📚 Student & Grade Management

Each student record contains information such as:

* Student Name
* Student ID
* GPA
* Completed Hours
* Grades

The system supports adding, editing, deleting, and displaying grades while automatically updating the student's academic information.

## 🏗️ Project Structure

The main components of the project include:

* `GradeNode` – Represents a node in the grade linked list.
* `Student` – Represents a student and manages their grades.
* `Queue` – Handles students waiting for processing.
* `HistoryNode` – Represents a history record.
* `HistoryStack` – Stores operation/search history.
* `StudentManager` – Manages the collection of students and provides searching and sorting operations.
